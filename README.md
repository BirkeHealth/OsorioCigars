# Osorio Cigars

A polished single-page cigar landing site for Osorio Cigars, built as a static HTML storefront. It includes a premium editorial layout, product highlights, brand story, testimonials, and a newsletter signup.

## Files
- `index.html` — complete landing page with embedded CSS

## Run locally
Open `index.html` directly in a browser, or serve the folder with:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deployment
This site is static and works well on GitHub Pages, Netlify, or Vercel with no build step required.
